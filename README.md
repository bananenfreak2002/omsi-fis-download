# OMSI-FIS

Fahrgastinformation (FIS) für [openOMSI](https://github.com/openOMSI-org/openOMSI): Außen- und Innenanzeigen,
Haltestellenansagen und ein Fahrerterminal – passend zum Fahrplan der Karte.

## Herunterladen

Die fertige Version liegt unter **[Releases](../../releases/latest)**:

- **OMSI-FIS-Setup-\<Version\>.exe** – Installer (empfohlen). Installiert das FIS und richtet alles ein.
- **OMSI-FIS-\<Version\>.zip** – dasselbe als Ordner zum Entpacken, ohne Installer.

Nach der Installation hält sich das FIS über diese Releases von selbst aktuell.
